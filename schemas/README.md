# NMD schemas

Copies of the official NMD format schemas, used to validate the XML the app
writes:

- `nmdechosounderv1.xsd` from https://www.imr.no/formats/nmdechosounder/v1/
- `bioticv3_1.xsd` from https://www.imr.no/formats/nmdbiotic/v3.1/ (its
  import of the NMD reference schema points to the local copy)
- `nmdreferencev2_1.xsd` from https://www.imr.no/formats/nmdreference/v2.1/
